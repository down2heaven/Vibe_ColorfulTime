### B-04 的影响说明

- 默认状态改名：`计算完成` → `计算完成/待查看`；需提供数据迁移（已有用户数据库中的该状态名称同步更新，任务数据不变）。
- 通知依赖 Windows 通知能力，需在“模块管理”中作为可选模块（可停用），停用后不发送通知但保留数据。
- “预计计算时间”与“预计计算时间到达”的判断需要定时器/后台任务，属于可选模块的后台工作；停用模块时必须停止轮询。
- API 自动获取计算时间属于网络 API 模块，当前只预留字段与接口位置，不实现开关假象。
