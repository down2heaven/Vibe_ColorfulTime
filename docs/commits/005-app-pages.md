# Commit 005 — feat(app): 功能页面与多彩 UWP / Windows Phone 风格界面

## 目标

完成 P0 的全部界面页面，并把视觉调整为“多彩 + UWP/Windows Phone 风格”，状态颜色条移动到条目文字下方。

## 页面

- `WorkbenchPage`（工作台）
  - 顶部问候与日期；**Windows Phone 风格纯色磁贴**快捷入口（新建任务 / 新建仿真任务 / 写今日总结 / 打开日历 / 打开清单 / 记录断点），跟随模块启停自动增减。
  - 8 类可配置卡片：今日待办、正在处理、正在计算的仿真任务、即将到期与已逾期、今日及近期日程、最近主题断点、最近每日总结、Checklist 进度；每张卡片有独立强调色条与“查看全部”。
  - 卡片内任务行在文字下方显示状态颜色条。
- `TasksPage`（任务）
  - 列表 + 详情双栏；标题行含彩色块；筛选（搜索/类型/状态/优先级/排序/仅未完成/仅逾期）。
  - 列表条目：状态色点 + 标题 + 优先级 + 交付提示 + 类型/状态/时间/标签 + **文字下方的加粗状态颜色条**。
  - 详情：状态徽标、完整字段、仿真信息、周期信息、文本备注、关联 Checklist 进度、编辑/删除/标记实际交付/关联清单。
- `CalendarPage`（月历）
  - 6×7 月视图，周日起始；每格最多 3 条彩色条目 + “还有 N 项”；今天/选中态高亮；右侧当日清单，可直接新建或编辑任务；上月/今天/下月导航。
- `DailySummaryPage`（每日总结）
  - 日期导航与日期选择、五个可留空区域、保存状态提示、关联当日任务勾选、关联 Checklist、历史记录列表（点击跳转日期）。
- `TopicLogPage`（主题日志/断点）
  - 搜索/类别/标签筛选；左侧主题列表；右侧编辑器（名称、类别、标签、当前断点、详细内容）；保存时旧断点自动入历史；历史记录列表与空状态提示；删除确认；关联清单。
- `ChecklistPage`（Checklist）
  - 左侧清单列表（进度条）；右侧名称/分类/备注编辑、检查项添加/编辑/勾选/上移下移/删除、进度展示、反向关联对象展示。
- `SettingsPage`（设置）
  - 外观与布局（主题、默认首页、恢复默认布局）；导航入口显示/隐藏与排序；首页卡片显示/隐藏与排序；任务状态管理（两组状态的新建/编辑/删除/排序，删除使用中状态时强制迁移）；模块管理（核心/可选/未实现状态徽标、启用与导航开关、未实现模块不显示开关）；数据与备份（路径、导出、导入合并/替换、打开目录）；关于与“当前版本未实现功能”说明。

## 视觉规范

- 每个模块固定主题色（任务蓝、日历紫、每日总结青、主题日志品红、清单绿），用于导航图标、页面标题色块、首页卡片色条。
- 统一轻量大标题、圆角卡片、磁贴与色块；无渐变、无多余装饰，保证读表效率。
- 深色模式下所有卡片/文字使用主题资源，状态色在深浅背景上均保持可读。
