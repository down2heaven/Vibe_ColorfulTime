## 第 13 节验收标准逐条

1. **创建仿真任务并填写关联计算任务、手动计算时间、创建/计划/实际交付日期** ✅ 数据自检 8 项；UI 新建任务流程通过。
2. **七种仿真状态可独立选择，名称/颜色可调整，并在列表、日历、详情保持一致** ✅ 状态为独立记录；列表与日历均取状态颜色；截图可见不同状态色条。
3. **一般任务使用通用状态，用户可自定义名称与颜色** ✅ 一般状态集合独立；`StatusEditorDialog` 支持改名与调色板/自定义色；
   支持“一般任务使用仿真状态集合”的共享开关。
4. **修改计划交付日期后日历同步更新** ✅ 数据自检直接验证。
5. **完成一次周期任务不会误将未来实例标为完成** ✅ 每个实例是独立任务行；数据自检验证。
6. **每日总结可以新增、编辑并查看历史日期** ✅ 按日期唯一记录；历史列表 + 上/下一天导航。
7. **主题断点能更新，同时保留历史** ✅ 更新时旧断点/旧内容写入 `topic_log_history`，默认不覆盖。
8. **Checklist 能创建、编辑、勾选、取消勾选；模板（P1）生成独立副本** ✅ 基础能力完成；模板按 P1 未实现（明确列入未完成项，不做假入口）。
9. **隐藏导航入口或首页卡片后数据仍保留** ✅ UI 隐藏/恢复入口验证；数据层验证隐藏后数据仍可查询。
10. **停用可选模块后后台工作停止，重新启用数据可用** ✅ 模块停用后入口不可访问、首页相关卡片隐藏；数据保留（模块无外部后台任务，属本地数据模块）。
11. **AI / 网络 API 可设计为独立开关，第一版不伪装成可用** ✅ 模块注册表已预留；UI 显示“不可用（未实现）”，不渲染开关。
12. **重启后数据、自定义状态、主题、模块开关、首页布局保持不变** ✅ 数据自检重启场景；UI 测试结束后的统计校验。
13. **备份/导出范围符合说明，导出文件可检查** ✅ JSON 可读、包含任务/状态/周期/总结/日志/断点历史/清单/关联/设置；导入合并去重、替换需确认。
14. **可选功能错误时主程序仍能启动** ✅ 启动阶段数据库异常会进入降级界面并显示原因；页面加载异常有兜底；实际验证过无数据目录写入权限时的降级界面。
