## 二、完成内容（P0）

1. **项目结构**：`SimWorkbench.sln` + 三层项目（Core 业务 / Data 存储 / App 界面）+ 测试与工具项目，依赖单向。
2. **界面**：UWP / Windows Phone 风格——轻量大标题 + 模块主题色块、纯色强调磁贴、彩色导航图标、卡片强调色条、加粗状态颜色条；支持浅色 / 深色 / 跟随系统一键切换。
3. **任务**：仿真/一般任务统一入口，创建、编辑、删除、列表、详情、搜索、类型/状态/优先级/逾期筛选与排序；仿真专属字段（算例、工况、手动计算所需时间、计算备注）；创建日期/计划开始/计划交付/实际交付均可维护。
4. **状态**：七种初始仿真状态 + 三种一般状态，独立存在、可改名改色排序；删除使用中的状态必须迁移任务。
5. **日历**：月视图（6×7），展示计划开始/计划交付/周期实例，颜色与状态一致，右侧当日清单可直接编辑任务。
6. **周期任务**：每日/每周/每月 + 自定义间隔、每周指定星期、可选结束日期；每次执行生成独立任务；支持跳过某次；修改规则重建今天及以后实例并保留历史。
7. **每日总结**：按日期唯一记录，五个可留空区域，关联当日任务与 Checklist，历史列表与日期导航。
8. **主题日志 / 断点**：长期主题、当前断点、详细内容；更新断点自动归档旧断点与旧内容到历史；类别/标签/搜索筛选。
9. **Checklist**：多清单、检查项增删改/排序/勾选、进度统计，可关联任务/每日总结/主题日志，支持反向查看关联。
10. **工作台首页**：8 类卡片（今日待办、处理中、计算中、到期/逾期、日程、断点、总结、清单进度），可显示/隐藏与排序；WP 风格快捷磁贴。
11. **界面与模块**：导航入口显隐与排序、首页卡片显隐与排序、默认首页、恢复默认布局；可选模块启用/停用（数据保留）；未实现模块显示“不可用（未实现）”，无假开关。
12. **数据**：SQLite 持久化 + `user_version` 迁移、WAL；JSON 备份导出/校验/合并导入/替换导入；数据目录可用 `--data-dir` 指定。
13. **可靠性**：数据服务失败时主程序仍启动并显示原因；页面加载异常有兜底；未处理异常写日志。

## 四、运行方法

```text
1) 环境：Windows 10 1809+ / Windows 11，.NET 8 SDK（仅开发构建需要）
2) 构建：dotnet build SimWorkbench.sln
3) 运行：src\SimWorkbench.App\bin\x64\Debug\net8.0-windows10.0.19041.0\win-x64\SimWorkbench.exe
   或直接使用 Release 压缩包解压后的 SimWorkbench.exe（无需安装运行时）
4) 便携数据目录：SimWorkbench.exe --data-dir <路径>
```

## 五、数据存储位置

- 默认数据库：`%LOCALAPPDATA%\SimWorkbench\workbench.db`
- 备份目录：`%LOCALAPPDATA%\SimWorkbench\backups\`
- 日志：`%LOCALAPPDATA%\SimWorkbench\logs\app.log`、`crash.log`
- 自动回退：LocalAppData → 文档 → 程序目录 `data\`（并用 InfoBar 提示路径）

## 七、已知限制

- 数据层为同步 SQLite，适合个人数据量级；未来可加异步封装。
- 周期实例按 30 天窗口惰性补齐（历史 3 天、未来 30 天），超过窗口的远期实例会在浏览日历/任务时补齐。
- 一般任务与仿真任务的状态集合“共享”通过开关实现复用，未提供任意集合组合的建模。
- 备份导入为记录级合并/整表替换，未做字段级冲突合并。
